## Current Architecture

### Environment Variable Flow
```
Cloudflare Workers fetch() 
  → setEnv(env) stores in _globalEnv
  → TanStack Start server functions
    → requireSupabaseAuth middleware
      → passes env in context
    → handler receives context.env
```

### Fallback Chain in getEnv()
1. **Primary**: `getRequest().context.cloudflare.env` (not working yet)
2. **Fallback**: `_globalEnv` (currently working)
3. **Last Resort**: `import.meta.env` (dev only)
